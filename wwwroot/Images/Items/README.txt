ITEM PHOTO FOLDER

Put each item photo in the folder that matches the item's CatID.

File name format:
<ItemCode>.jpg

Example:
wwwroot/Images/Items/1/GOW-001.jpg
wwwroot/Images/Items/1/GOW-002.jpg
...
wwwroot/Images/Items/1/GOW-015.jpg

Every category should have at least 15 items for the capstone requirement.
The Item Code is generated automatically when the admin creates an item.

For category 2:
wwwroot/Images/Items/2/<ItemCode>.jpg

Supported common image format in this setup: JPG.
If a photo is missing, the customer pages show a default image instead.
